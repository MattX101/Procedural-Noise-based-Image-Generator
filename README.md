# Procedural Noise based Image Generator

Harness the power of noise functions and colour theory to generate an infinite number of images.

This project set out to provide the necessary tools to allow the generation of noise-based images for whatever scenario they are needed.
This project was developed out of my interest in building projects that use procedural content generation as their main core feature.
This application is aimed towards like minded individuals who share my passion for procedural content generation.

# Technologies Used
- Unity
- C#
- HLSL

# Architecture

Unity Runtime → Runtime Node Editor  → Unity UI\
Unity Runtime → Runtime Node Editor  → MattX101 Utils\
Unity Runtime → Runtime Node Editor  → MattX101 Utils → FastNoiseLite

# Features

__Key Features__
- Noise
- Colouring
- Blending
- Filters

__Other Features__
- Full Parameter Access
- Live Preview
- Image Export

# Getting Started

To execute the pre-built project simply do the following:
- **Windows** – Run PNE.exe
- **Linux** – Run PNE.x86_64

To open the project Unity 2022.3.13 is required.

The following repositories are needed for the project to execute:
- Runtime Node Editor
- MattX101 Utils
